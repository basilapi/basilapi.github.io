BASIL ontology

Terms used by BASIL to describe the APIs, users and views it stores.

Namespace: http://basilapi.github.io/ontology/ns# · Turtle: basil.ttl

Stored data uses the namespace configured as basil.namespace (by default http://basilapi.github.io/data/ns/).

Classes

TermDescription
ApiAn API: a SPARQL endpoint and a query, with its views, documentation and aliases.
UserA user of a BASIL instance, owner of APIs.
ViewA template or script that post-processes the result of an API.
